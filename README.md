# TRAFFIX – Intelligent Traffic Management System

**A Smart Approach to Traffic Monitoring and Signal Management**

## Project Overview
TRAFFIX is a web-based Intelligent Traffic Management System designed to demonstrate how technology can help monitor traffic conditions and improve signal management.

The system provides a simulated traffic monitoring environment, displays traffic density, and estimates signal timing based on traffic conditions.

## Key Features
- User Registration and Login
- Admin Dashboard
- Traffic Density Monitoring
- Simulated Traffic Signal Management
- Estimated Signal Timing
- User Traffic Issue Reporting
- Admin Issue Management
- Responsive Web Interface

## Digital Electronics Concepts Used

TRAFFIX demonstrates the application of Digital Electronics concepts through software-based traffic simulation and logical decision-making.

- **Priority-Based Logic:** Selects the direction with the highest traffic volume to receive priority.
- **Combinational Logic:** Uses traffic-related inputs, such as vehicle count and density, to determine the appropriate signal timing.
- **Digital Control Logic:** Represents traffic management as a rule-based decision system for controlling signal timing.

**Note:** These concepts are demonstrated through software simulation and logical modelling rather than physical digital circuits or hardware components.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Purpose
The main objective of TRAFFIX is to demonstrate a technology-based approach to traffic monitoring and management through a simple and accessible web platform.

**Note:** This is an academic prototype. Traffic data and signal decisions are simulated and are not connected to real-world traffic infrastructure.
